# Royal63

Сайт покерного клуба с расписанием, заявками, результатами и рейтингом,
панелью организатора и Telegram-ботом.

## Стек

- **Next.js 16** (App Router, React Server Components, Server Actions)
- **TypeScript** (strict)
- **Tailwind CSS v4** + тёмная дизайн-система с золотыми акцентами
- **Drizzle ORM** поверх встроенного `node:sqlite` — без нативной
  компиляции, работает одинаково на Windows/macOS/Linux
- **`jose`** (JWT в httpOnly-cookie) для авторизации, `proxy.ts`
  защищает `/admin/dashboard`
- **Framer Motion** (`motion`) для анимаций, `cmdk` — командная палитра
  в админке (⌘K / Ctrl+K)

## Запуск локально

Требуется Node.js 22.5+ (используется `node:sqlite`).

```bash
npm install
npm run dev
```

Откроется на `http://localhost:3000`.

## Панель организатора

Доступна по адресу `/admin/login`.

При первом локальном запуске без переменных окружения создаётся тестовый администратор:

- логин: `admin`
- пароль: `admin123`

Для реального использования задайте `ADMIN_USERNAME`, `ADMIN_PASSWORD`
и `JWT_SECRET` до первого запуска. В production пароль обязателен.
Если локальная база уже содержит тестового администратора, смена переменных
окружения не изменит существующий пароль: его нужно отдельно обновить.

В админке есть командная палитра — `⌘K` (Mac) / `Ctrl+K` (Windows/Linux).

## Учёт турниров и рейтинг

Рабочий цикл: создать турнир → обработать заявки → отметить явку → рассадить
игроков → вести ребаи, аддоны и выбывание → указать итоговые места → завершить
турнир. Во вкладке «Учёт и рейтинг» организатор видит поимённый журнал и
сводки по турнирам и игрокам; каждую таблицу можно выгрузить в CSV.

Рейтинг начинается с 1000 очков. После завершения турнира игрок получает
или теряет очки по занятому месту относительно числа участников. Верхняя
половина получает очки, нижняя теряет; величина изменения растёт с размером
турнира. История изменений хранится отдельно, поэтому рейтинг можно
проверить по каждому турниру. Скрытые тестовые турниры в рейтинг не входят.

Telegram-бот принимает заявки, показывает их статус (`/status`), ближайший
турнир (`/tournaments`), отменяет заявку до начала игры (`/cancel`) и
объясняет порядок действий (`/help`). В чате организаторов доступны поиск
игрока и список участников. Для работы задайте переменные из `.env.example`.

## Контент, который нужно заменить перед реальным запуском

- `lib/content.ts` — история клуба и контакты: проверьте перед запуском
- `app/(site)/legal/page.tsx` — шаблон политики обработки персональных
  данных, требует заполнения реквизитов и проверки юристом
- Фотография в `components/hero/hero.tsx` — замените изображением зала,
  когда появятся подходящие материалы
- Иллюстрации News — замените реальными изображениями при необходимости

  **Важно:** легальность проведения турниров с денежными баай-инами в
  РФ регулируется отдельно (ФЗ-244 об азартных играх, статус
  «спортивного покера») — это должен подтвердить профильный юрист,
  сайт сам по себе этого не гарантирует.

## Структура проекта

```
app/            страницы (App Router)
  (site)/       публичные страницы: главная, турниры, новости, о клубе, правовая информация
  admin/        логин и панель организатора (защищено middleware.ts)
components/     UI-компоненты, включая components/ui — примитивы дизайн-системы
lib/
  db/           Drizzle-схема, клиент, сид
  actions/      Server Actions (турниры, новости, авторизация)
  auth/         сессии (JWT в cookie)
public/         статика, иконки PWA, service worker (sw.js)
```

## Сборка для продакшена

```bash
npm run build
npm run start
```

## Проверка сценариев Telegram

`node --experimental-sqlite --import tsx tests/bot-flows.ts`

Проверка использует временную базу и подмену Telegram API: никаких сообщений
игрокам не отправляется. Покрывает запись по шагам, передачу контакта, проверку
телефона, старые кнопки, подтверждение отмены, дубли, скрытые турниры и рассадку.
Реальную доставку сообщений нужно отдельно проверить на настроенном сервере.

## Дизайн

Сохранена тёмно-золотая палитра Royal63. Визуальные ориентиры:
[Poker Club Management](https://pokercm.com/) — заметные события и расписание;
[POKER BOOM](https://poker-boom.ru/) — выразительная типографика, запись и результаты.
Используется собственное изображение Royal63; материалы других клубов не перенесены.
Анимация фоновой карты отключается при системной настройке уменьшения движения.
