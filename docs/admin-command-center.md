# Royal63: пульт турнира для организатора

## Что уже работает

- Заявки и подтверждение игроков, QR-регистрация, рассадка и перебалансировка столов.
- Ребаи, аддоны, выбывание, журнал действий, закрытие турнира и пересчёт рейтинга.
- Таблица учёта турниров и сводка для организатора.

## Идея следующего модуля

Добавить в существующую закрытую `/admin/dashboard` отдельный экран **«Пульт турнира»**, доступный только вошедшему администратору. Это один рабочий экран на вечер: слева крупный таймер текущего уровня с блайндами и следующим уровнем, справа число игроков, занятые места, события и быстрые действия. Телефон организатора показывает компактные кнопки «Пауза», «Следующий уровень», «Ребай», «Выбыл». Отдельный режим на телевизоре показывает только таймер и публичные показатели без кнопок и внутренних данных.

## Порядок разработки

1. **Структура блайндов:** шаблоны уровней, анте, длительности и перерывов; копирование структуры в новый турнир.
2. **Надёжный таймер:** сервер хранит время старта, паузы и номер уровня; перезагрузка страницы не сбрасывает отсчёт. Изменение уровня записывается в журнал действий.
3. **Экран зала:** крупные текущие и следующие блайнды, время до перерыва, число игроков и средний стек. Без заявок, телефонов, платежей и управляющих кнопок.
4. **Финализация:** после выбывания последнего игрока организатор проверяет места, подтверждает результат и публикует рейтинг. Возможность исправить ошибку с записью причины.
5. **Права:** вход в админку обязателен для управления; публичный экран получает отдельный ограниченный маршрут с одноразовой привязкой к турниру. Позже можно добавить роль помощника с меньшими правами.

## Что взято из анализа аналогов

PokerManager наглядно показывает таймер, структуру блайндов, рассадку и PTS в одном кабинете. PokerOS делает акцент на связке лайв-турнира, мини-приложения и рейтинга. Snap Call и Poker Club Admin соединяют регистрацию, посадку, таймер и результаты в одной записи турнира. Для Royal63 разумно развивать уже существующую базу и интерфейс, а не переносить данные в отдельный сервис.
